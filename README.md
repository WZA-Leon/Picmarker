# Picmarker V1.3 - 专业图片水印工具

## 软件概述

Picmarker 是一款面向摄影爱好者、自媒体创作者和图片版权保护需求者的专业图片水印工具。软件采用 Python 开发，基于 Tkinter 图形界面框架，提供直观易用的操作体验。目前版本为V1.3，这一版本为Pickmarker自V1.0最基础简单版本(只能添加明文水印)以后的一个全面升级的大版本，集成了**边框水印**、**明文水印**和**隐形水印**三大核心功能，支持批量处理，能够高效地为照片添加专业级版权标识。

## 核心功能

### 1. 添加边框（EXIF 信息水印）

自动读取照片的 EXIF 信息（相机品牌、型号、镜头、焦距、光圈、快门、ISO、拍摄时间等），在图片底部生成一个信息条。支持：

- 自动识别相机品牌并显示对应品牌图标
- 自定义字体选择（支持系统所有已安装字体）
- 可编辑 EXIF 信息，支持手动修改
- 支持品牌-相机-镜头三级联动选择

### 2. 明文水印（可见水印）

在图片表面叠加用户自定义的可见水印文字，支持：

- 自定义水印文字内容
- 多种字体选择
- 字体大小调节（10-100px）
- 五种颜色选择（黑、白、红、蓝、绿）
- 加粗样式
- 45° 倾斜散布排列，覆盖全图

### 3. 隐形水印（DWT 小波变换）

基于离散小波变换（DWT）的盲水印技术，将版权信息嵌入图片的频域中，人眼不可见。支持：

- 密码保护（默认 123456）
- 自定义加密内容
- 嵌入与提取双模式
- 抗裁剪、抗压缩能力强
- 支持大图，无尺寸限制

### 4. 批量处理

- 支持多张图片同时添加/删除
- 复选框选择要处理的图片
- 实时预览效果
- 进度条显示处理进度
- 自动保留原始 EXIF 信息

## 使用场景

| 场景 | 适用功能 |
|------|----------|
| 摄影作品发布 | 边框水印展示相机参数，提升专业感 |
| 自媒体内容保护 | 明文水印防止盗图 |
| 版权溯源 | 隐形水印嵌入版权信息，维权取证 |
| 摄影器材评测 | 边框水印展示 EXIF 参数 |
| 批量图片处理 | 同时处理数百张照片 |

## 运行环境

- **操作系统**：Windows / macOS / Linux（跨平台兼容）
- **Python 版本**：Python 3.8+
- **依赖库**：`Pillow`、`piexif`、`exifread`、`pywt`、`numpy`
- **硬件要求**：无特殊要求，建议 4GB 以上内存

## 跨平台兼容性

Picmarker 基于 Python 和 Tkinter 开发，天然具备优秀的跨平台能力，可在 **Windows、macOS、Linux** 三大主流操作系统上无缝运行。无论你使用哪种系统，都能获得一致的操作体验和完整的全部功能支持。软件依赖库均为跨平台库，无需额外适配即可在不同系统上正常工作，真正做到"一次开发，多系统使用"。

## 技术架构

- **GUI 框架**：`Tkinter` + `ttk` 主题组件
- **图像处理**：`Pillow (PIL)`
- **EXIF 读写**：`exifread`（读取）+ `piexif`（写入）
- **隐形水印**：`PyWavelets (DWT)` + `NumPy`
- **配置管理**：JSON 配置文件（`settings.json`）

2. **水印预设系统**：保存用户常用水印配置为预设，一键切换
3. **深度用户自定义GUI**：
4. **图片格式转换**：支持批量转换输出格式（JPG/PNG/TIFF/WebP）

## 总结

Picmarker 是一款轻量级但功能强大的图片水印工具，特别适合摄影爱好者和内容创作者使用。它集 EXIF 信息展示、可见水印、隐形水印于一体，提供批量处理和实时预览，是图片版权保护和图片美化的得力助手。虽然现在功能相对简易，但是WZA未来将持续升级该软件，增加更多实用功能，打造一站式的图片处理解决方案。
